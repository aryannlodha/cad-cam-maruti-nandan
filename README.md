# 🛠️ CAD/CAM Design and CNC Machining — Maruti Nandan

> An end-to-end CAD/CAM project covering digital design, CAM toolpath generation, CNC machining and industrial manufacturing exposure.

## 🚀 Overview

This project demonstrates the complete **CAD → CAM → CNC** workflow through the design and machining of the **“Maruti Nandan”** engraved plaque using Autodesk Fusion 360 and a 3-axis CNC milling machine.

The work also includes structured industrial visits to manufacturing facilities in Peenya, Bengaluru, connecting classroom concepts with real shop-floor practices in CNC machine manufacturing, heavy equipment production and sheet-metal fabrication.

## ⚙️ Workflow

Concept → CAD Modelling → CAM Toolpaths → Simulation → NC Code → CNC Setup → Machining → Inspection

## ✨ Key Work

- 🎨 Parametric CAD modelling in Autodesk Fusion 360
- 🧰 CAM toolpath generation and simulation
- 🧾 NC/G-code generation for CNC machining
- 🏭 Physical machining of the designed plaque
- 📏 Dimensional inspection and design-conformance checks
- 🏗️ Industrial study of CNC, CAD/CAM, automation and manufacturing systems

## 📌 Project Result

The completed prototype was documented with dimensional conformance within approximately **±0.2 mm** for the checked features in the project report.

## 🏭 Industry Exposure

The project included visits to:

- **Sands Precision Pvt. Ltd.** — CNC machine tool manufacturing
- **United Concord Industries** — heavy industrial pelletizing equipment
- **Sree Ranga Engineering Works** — CNC laser cutting and sheet-metal fabrication

The visits provided exposure to machine utilisation, CAD/CAM integration, metrology, process planning, material flow, nesting and shop-floor automation.

## 🛠️ Tools & Technologies

**Autodesk Fusion 360 · CAD · CAM · CNC Milling · G-code / NC · Vernier Calipers · CNC Metrology**
